### Scenario F — End-to-end install smoke against draft v0.1.0 (auth-mirror pattern)

The CANONICAL public curl-pipe-sh form (`curl raw.gh.../install.sh | sh`) will
**correctly 404** while the release is still in DRAFT state — this is GitHub's
auth gate, not a release defect (per handoff §"Empirical curl-pipe-sh smoke" §B).
To smoke-test the binary stream before CEO promotion, use the authenticated
mirror pattern. Release already executed this; Manual Test re-runs end-to-end:

```sh
mkdir -p /tmp/v010-smoke && cd /tmp/v010-smoke

# Fetch the draft binary + sidecar via authenticated gh CLI:
gh release download v0.1.0 -p 'novetest-linux-x86_64*' -D ./assets

# Mirror at canonical CDN layout via a localhost HTTP server:
mkdir -p ./mirror/v0.1.0 && cp ./assets/* ./mirror/v0.1.0/
( cd ./mirror && python3 -m http.server 28100 ) &
SERVER_PID=$!
sleep 1

# Fetch the install script from the v0.1.0 tag's raw.gh.com CDN:
curl -fsSL https://raw.githubusercontent.com/Nove-Lab/Nove-Test/v0.1.0/scripts/install.sh \
  -o ./install.sh
chmod +x ./install.sh

# Run install.sh against the local mirror:
NOVETEST_INSTALL_BASE_URL=http://127.0.0.1:28100 \
  NOVETEST_INSTALL_PREFIX=/tmp/v010-smoke/install-prefix \
  ./install.sh

# Verify SHA-256 sidecar matches the binary:
LOCAL_SHA=$(sha256sum ./assets/novetest-linux-x86_64 | awk '{print $1}')
SIDECAR_SHA=$(awk '{print $1}' ./assets/novetest-linux-x86_64.sha256)
[ "$LOCAL_SHA" = "$SIDECAR_SHA" ] && echo "✓ SHA-256 matches" || echo "✗ SHA-256 MISMATCH"

kill $SERVER_PID
```

Expected from `install.sh` output: `SHA-256 verified (3d152e7b70c54d08a07fcdefb4bc1d15e5b99ccc353711c1e301b597e819ec97).`
followed by `Installed: /tmp/v010-smoke/install-prefix/novetest`. Re-running
the script should be idempotent (same `SHA-256 verified` line, same install).

**Host-equip caveat**: Executing `./install-prefix/novetest --version` on this
dev host (Ubuntu 22.04, glibc 2.35) fails with a glibc mismatch — the binary
is built against `ubuntu-latest` (Ubuntu 24.04, glibc 2.39). This is a
**dev-host glibc mismatch on the runner side, NOT a release defect** — the
release-test.yml install-script-e2e job (job `80472397159`) successfully ran
the same install + execute flow on `ubuntu-latest`. Manual Test can skip the
runtime exec step or chase it on a 24.04 host; per handoff this is expected.
