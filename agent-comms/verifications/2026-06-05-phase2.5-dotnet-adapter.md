**Expected** (all observed verbatim in this session):
- **Exit code = 3** (`EXIT_USER_TESTS_FAILED`; per `src/novetest/cli/output.py:15`). NOT exit 1, NOT exit 2.
- **`ok = true`** in the envelope JSON.
- **`errors == []`** — no errors emitted on a clean test-run-with-failures.
- **`data.memory_entry.run_record.engine_name == "xunit"`** — the engine name is `xunit` (NOT `dotnet`, NOT `dotnet-test`).
- **`data.memory_entry.run_record.engine_version == "8.0.421"`** (or whatever `dotnet --version` returns on the host).
- **`data.memory_entry.run_record.target_expression == "."`** AND **`data.memory_entry.run_record.target_type == "directory"`** — user input preserved on audit trail.
- **`data.memory_entry.run_record.summary_counts == {"errored": 0, "failed": 1, "passed": 2, "skipped": 0, "total": 3}`** — the canonical fixture's contract (note `errored` key is in the schema; will be 0 for this fixture). 1 fail unit + 2 pass (1 plain + 1 parametrized).
- **`data.memory_entry.run_record.status == "failed"`** (because `TestSubtractIntentionallyFails` fails by design).
- **`data.memory_entry.run_record.metadata`** contains all three keys: `dotnet_sdk_version`, `native_exit_code` (= 1, the `dotnet test` exit on test failure), `xunit_version` (= `2.6.0`).
- **`data.memory_entry.run_record.test_results`** is a 3-element list with these `node_id`s (order may vary by run, but all 3 must be present):
  - `MathLib.Tests.MathTests.TestAddPasses` → outcome `passed`
  - `MathLib.Tests.MathTests.TestParametrized(a: 1, b: 2, expected: 3)` → outcome `passed` (the xUnit `[Theory]` test — note the parametrized identity preservation)
